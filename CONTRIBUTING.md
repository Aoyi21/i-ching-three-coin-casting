# Contributing

Corrections are welcome, especially when they improve reproducibility, line-order clarity, probability explanations, or cultural accuracy.

Before opening a change:

1. Keep arrays in bottom-to-top line order.
2. Do not add copyrighted modern translations or long interpretive texts.
3. Do not add prediction guarantees, fear-based claims, or instructions that replace medical, legal, financial, or safety judgment.
4. Add or update tests when changing the procedural contract.
5. Run `npm test`.

Please describe whether your proposal changes the casting method, only clarifies documentation, or corrects a factual error. Method changes require a new method-version identifier.
