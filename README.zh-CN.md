# 易经三枚铜钱起卦：透明、可验证的参考实现

这是一个面向学习者和开发者的公开方法仓库。它完整说明怎样用三枚铜钱、六次投掷形成六爻，并用可运行测试验证计算过程。

方法只有六步：

1. 预先约定铜钱一面记 `3`，另一面记 `2`。
2. 每次投掷三枚铜钱，共投六次。
3. 第一次结果是初爻，放在最下方，之后逐爻向上。
4. 总数 `6`、`7`、`8`、`9` 分别表示老阴、少阳、少阴、老阳。
5. 六爻共同形成本卦。
6. 如果存在动爻，把所有动爻同时变成相反阴阳，得到唯一的之卦。

问题、界面、动画、AI 或后来的解读都不能修改六次投掷，也不能重选卦象。

> 这个仓库只说明起卦程序。它不是《易经》译本，不自称经典权威，也不承诺预测未来。

## 四种爻态

| 总数 | 名称 | 本卦爻态 | 变化后 | 单次概率 |
|---:|---|---|---|---:|
| 6 | 老阴 | 阴，断线 | 阳 | 1/8 |
| 7 | 少阳 | 阳，实线 | 阳 | 3/8 |
| 8 | 少阴 | 阴，断线 | 阴 | 3/8 |
| 9 | 老阳 | 阳，实线 | 阴 | 1/8 |

概率来自三枚双面铜钱的八种等可能结果。铜钱哪一面记 `2`、哪一面记 `3` 必须在起卦前确定，并在六次投掷中保持一致。

## 为什么必须自下而上

本仓库中的数组固定按初爻到上爻排列：

```text
index 5  -> 上爻，第六爻
index 4  -> 第五爻
index 3  -> 第四爻
index 2  -> 第三爻
index 1  -> 第二爻
index 0  -> 初爻，最下方
```

这不是排版习惯。把顺序倒过来，可能得到另一个卦。

## 验证范围

测试包括：

- 单次投掷的全部八种铜钱结果；
- `6:7:8:9 = 1:3:3:1` 的组合数量；
- 64 种阴阳六爻结构与独立文王卦序表；
- `4^6 = 4,096` 种六爻状态组合；
- 动爻、之卦、自下而上顺序和异常输入；
- 无动爻时不虚构之卦。

`4,096` 指每爻四种状态形成的组合数。如果保留每一枚铜钱的正反面，六次投掷共有 `8^6 = 262,144` 种原始结果。两者不是同一个数字。

运行测试：

```bash
npm test
```

仓库不依赖第三方包。

## 边界

- 铜钱结果是唯一随机输入。
- 第一次投掷永远是最下方的初爻。
- 所有动爻都必须保留，不能偷偷只选一爻。
- 没有动爻时，不生成之卦。
- 之卦是由动爻推导出的关系结构，不等于确定未来。
- 问题只提供阅读语境，不能改变卦象。
- 仓库不包含用户问题、起卦历史、身份、统计数据或现代版权译文。

如果想看图文步骤或亲自体验，可以打开：[三枚铜钱起卦英文指南](https://ichingreflection.com/how-to-cast/)。
